# تقرير فحص دمج SL.Tube في SatLink Browser PRO 1.9.5

التاريخ: 2026-10-04

## المصادر التي فُحصت

- SL.Tube-4.5.3-sltube.3-source-unbuilt.zip: أحدث مصدر مطابق وجد في الملفات.
- SatLinkBrowser-PRO-1.9.4-reviewed-source.zip: مصدر المشروع الهدف.
- روجعت ملفات المحرك وطلبات التحليل والتنزيل واختيار الصيغ وإضافة الالتقاط في SL.Tube. المشروعان يستعملان library/ffmpeg 0.18.1؛ لا يوجد محرك NewPipe في مسار التحليل المرجعي.

## ما نُقل وكُيّف

ملف yt-dlp 2026.08.19 نُقل بدون تعديل، ويحتوي yt_dlp_ejs وcore.min.js وlib.min.js. SHA-256:

`1fa6733c37ea6fb51c99ad8fe785e7b7e5f3246c9b980230329d4fb72ed8d4d6`

كُيّفت إعدادات QuickJS/EJS وlegacy-server-connect، وقراءة HLS master، واختيار صيغة فيديو مع صيغة صوت متوافقة. لم تُنسخ أخطاء المسار المرجعي التي كانت قد تحوّل URI لجزء TS داخل media playlist إلى بطاقة جودة أو تنقل أبعاد المشغل إلى كل طلب شبكة. يعتمد المشروع على الأبعاد المعلنة لكل جودة، ويعزل النتائج حسب الصفحة والتبويب.

أضيف تثبيت محرك موحّد قبل جاهزية الالتقاط وخدمة التنزيل، مع منع الرجوع إلى إصدار أقدم والتحقق والتراجع عند الفشل. بقي التحديث التلقائي الحالي للمحرك مفعلاً. لم تُنقل شاشة SL.Tube أو تاريخ تنزيلاته أو كامل مدير تحديث إضافاته.

## فحوص نفذت ونجحت

- capture.test.cjs: الإرسال المبكر والتلقائي، جدولة DOM، MKV/TS، Content-Range، جلسات الإطارات، وتنظيف التنقل وعزل الشبكة مجهولة التبويب.
- player_metadata.test.cjs: الدقة/الفريمات/الحجم والترميز من JSON، عدم اعتبار signatureCipher المشفر رابطاً، ودمج سبعة طلبات أجزاء في جودة واحدة مع صوتها، واستبعاد UMP.
- hls.test.cjs: قوائم 360p و1080p60 و4K، روابط نسبية وموقعة، مجموعات صوت، محدد الجودة، عدم تحويل الأجزاء إلى خيارات، الحفاظ على جلسة الطلب، عدم تكرار القراءة لكل variant، ومنع دخول نتيجة قائمة قديمة لصفحة جديدة.
- format_rules_test.py: دوال Java الفعلية لصيغ MKV/TS/AV1 وتصحيح 1080p60.
- format_parser_test.py: تشغيل parseFormats الكامل ببدائل JSON للقراءة؛ ترتيب 8K ثم 4K ثم 1080p، اختيار الصوت المحدد، الحاوية المتوافقة وMKV عند الحاجة، أربع وجهات MP3، صوت الفيديو المدمج، استبعاد المعاينة وDRM، وعلامة الحجم التقريبي.
- download_plan_test.py: خطة بيانات التنزيل المباشر من روابط الشبكة الفعلية، دمج مسارين، MP3 من فيديو بصوت، روابط التوقيع، ومسار QuickJS.
- download_request_test.py: تشغيل buildRequest وTaskState الفعليين ببدائل Android صغيرة؛ صيغة الفيديو+الصوت الدقيقة، تجديد رابط الصفحة، جلسة المتصفح، EJS، قائمة HLS موقعة بلا امتداد، الدقة المختارة، حفظ بيانات الإيقاف والاستئناف، استخراج MP3 وخطة MKV.
- bundled_engine_test.py: تشغيل مثبت المحرك الفعلي على الملف المنقول؛ تطابق البايتات وSHA-256، تثبيت جديد، ترقية، إبقاء الأحدث، استعادة السابق عند فشل التحقق، رفض ملف تالف، وتنظيف الملفات المؤقتة.
- شغّل Python المضيف ملف المحرك الحقيقي بواسطة --version وأرجع 2026.08.19. تحقق وجود ملفات EJS داخل أرشيف المحرك.
- تحليل قواعد Java بجميع الملفات نجح؛ node --check لكل JavaScript نجح؛ XML ومعرفات R.id ومراجع ملفات manifest نجحت.

## حدود الفحص الفعلية

محاولة `bash gradlew :app:assembleDebug --console=plain` توقفت عند تنزيل Gradle 8.11.1 برسالة Network is unreachable، قبل تجميع أندرويد. لا يوجد APK جديد في الحزمة.

اختبارات Java تستعمل بدائل صغيرة لـAndroid/JSON/YoutubeDLRequest وتنفذ المنطق الإنتاجي، وليست تحقق أنواع Android/GeckoView كاملاً. تنفيذ --version تم على Python المضيف، وليس على هاتف. لم يحصل استخراج حي للفيديو في الصورة، أو تنزيل/دمج فعلي على أندرويد. اختبارات SL.Tube التاريخية الواردة داخل مشروعه ليست نتائج تحقق لهذا الدمج.

لا يمكن إعلان خلو التطبيق من كل خطأ أو تأكيد حل مشكلة 360p على الهاتف قبل البناء والتجربة الحية. ملفات المصدر والاختبارات وتقرير الحدود مرفقة كاملة.
