إضافة ملء شاشة الفيديو — 10 أكتوبر 2026

ملء تلقائي للفيديو عند دخول ملء الشاشة باستخدام cover مع الحفاظ على النسب، دون تمديد أو تغيير الدقة. يتكيّف مع قياس نافذة العرض والتدوير. زر «عرض كامل» يرجع contain ويظهر الصورة كاملة، ثم يمكن اختيار «ملء الشاشة» مجدداً. التكبير قد يقص الأطراف والترجمة الموجودة ضمن الصورة. في ملء الشاشة المباشر لعنصر الفيديو، بدلاً من حاوية المشغل، التبديل بنقرة بإصبعين أو مفتاح Z؛ زر إضافي لا يظهر داخل عنصر فيديو أصلي.

الإضافة عامة لمشغلات HTML video في الصفحات والإطارات التي تسمح بحقن إضافة المتصفح؛ ليست ضماناً لكل منصة. لا تغير الملف المصدر أو تشغيل/إيقاف الفيديو أو سرعة التشغيل أو محرك الالتقاط أو التنزيل. لا تزيل حواف سوداء مرسومة داخل ملف الفيديو، ولا تغير إعدادات overscan للتلفزيون. عند الخروج تعيد خصائص العرض التي عدلتها فقط. لا تغيير لإصدار 1.9.8.

فحص مطابقة كل ملفات التطبيق الموجودة مع المشروع السابق: الملف الوحيد الذي تغير هو manifest.json لإضافة تسجيل fullscreen_fit.js، والسكربت ملف جديد مستقل. MainActivity وكود التحميل والالتقاط ومحركات الصوت والفيديو مطابقة بايتاً للنسخة السابقة.

اختبارات منطق العرض تعمل على محاكاة DOM: تكبير/عرض كامل، دوران وحجم، استعادة CSS، استبدال المشغل، خروج الصفحة، إطارات غير قابلة للوصول. الاختبارات القديمة مرفقة. فحص Java هو فحص صياغة فقط؛ لم يتغير أي ملف Java. تعذر assembleDebug بسبب Network is unreachable أثناء تنزيل Gradle 8.11.1. لم يصدر APK ولم يختبر العرض على موبايل أو TV Box فعلي؛ الحزمة مشروع مصدر.
